# Supplier Ikan Hias Santo Group

Landing page berbahasa Indonesia untuk Supplier Ikan Hias Santo Group, dibuat
dengan Next.js App Router, Tailwind CSS, dan Framer Motion.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).

## Perintah

- `npm run dev` — menjalankan server pengembangan.
- `npm run build` — mengekspor situs statis ke folder `out`.
- `npm run typecheck` — memeriksa tipe TypeScript.

Galeri mendukung kontrol keyboard, termasuk Escape dan pengelolaan fokus.
Animasi menghormati preferensi `prefers-reduced-motion`.
